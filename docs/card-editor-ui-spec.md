# 卡片编辑器 UI 结构说明（iOS v1.2 / card editor v3）

> 用途：给 Android 卡片编辑器对齐同一套页面结构、文案、控件与交互行为。
> 版本：iOS 1.2 / build 3；设计风格保持奶油纸底 + 衬线排版，**本轮不新增装饰**。
> 截图目录：`ios/artifacts/verify-1.2-card-editor/`（Android 照此实现 UI）。

---

## 1. 入口

- 配方详情页：内容区中部「做一张宣传卡片」卡片（副标题「随杯卡 · 可 AI 生成文案」，已保存时显示「已保存」标签）→ 打开卡片编辑器。
- 菜单页：每个配方行右侧「卡片」按钮 → 打开该配方的卡片编辑器。

## 2. 卡片编辑器主页面（从上到下）

顺序固定：

1. **顶部栏**（高约 56pt）
   - 左：圆形返回按钮（chevron.left）
   - 标题区：Overline `PROMO CARD` + 标题「宣传卡片」
   - 右：胶囊主按钮「✓ 保存」（lime 背景，深墨文字；有重叠冲突时禁止保存并提示）
2. **提示条**（可选，出现时在顶部栏下方）：浅 lime 圆角条，左侧 ✓ 图标，右侧 × 关闭；用于「AI 已生成并套用 / 已保存 / 已恢复自动排版 / 元素重叠已回退」等反馈。
3. **实时预览区**
   - Overline `LIVE PREVIEW`，右侧一行小字：`模板名 · 比例名 · A6 打印/社交`
   - 卡片本体（A6 比例；选中「社交尺寸」时宽高比随导出尺寸变化）
   - 编辑布局时，卡片上叠加元素选区（见 §5）
   - 卡片下方一行说明：`A6 300dpi 打印尺寸：<宽>×<高> px，浅色纸打印效果最佳`
4. **工具栏两行**（每行 3–4 个白底圆角按钮，图标 + 10.5pt 文案）
   - 第一行：`设计工具` / `AI 插画` / `导入图片`（已有导入图时文案变「换导入图」）/ `AI 文案`
   - 第二行：`编辑布局`（编辑中变「完成布局」）/ `导出到相册` / `分享 / 打印`
5. **导出尺寸选择**
   - 两个小胶囊：`社交尺寸` / `A6 打印 300dpi`（选中项 limeSoft 底 + lime 描边）
   - 下方 9.5pt 灰字：`<说明> · <宽>×<高> px · PNG`
     - 社交：`导出分享图 · 1200×1600 px`（竖）/ `导出分享图 · 1200×675 px`（横）
     - A6：`咖啡店随杯卡可打印 · 1240×1748 px`（竖）/ `1748×1240 px`（横）
6. **保存区**：lime 主按钮「保存到「<配方名>」」（已保存/有冲突提示同上），下方 10.5pt 灰字「卡片配置会跟着这杯配方一起保存在本机，导出 / 备份数据时一起带走。」
7. **说明卡**：小圆角卡「怎么用」+ 一段说明文字（AI 插画/文字工具/导出打印）。

## 3. 设计工具面板（底部 sheet，标题「设计工具」）

从上到下：

| 区块 | 控件 | 取值/说明 |
| --- | --- | --- |
| 顶部 | 卡片实时预览 | 与主页面同一渲染 |
| 比例 | `A6 横版` / `A6 竖版` 两个胶囊 | 切换后当前方向重新使用独立的自动/手动排版 |
| 模板 | 3 个卡片：杂志 / 海报 / 留白 | 每个含标题 + 一句说明；选中 limeSoft 底 + ✓ |
| 主题色 | 8 个圆形色点 + 1 个系统取色器 | 色值：A3CD39、6B4A33、26231F、D7BC62、B77A6A、6E8F9D、7E9C4F、C08A3E；自定义 ColorPicker |
| 封面 | 4 个方块按钮：`AI 插画` / `相册导入` / `杯图` / `豆插画` | 下方按类型显示管理区域：相册图 → PhotosPicker；AI 插画 →「去生成」；相册导入 → 已导入状态 + 「重新导入 / 自动抠图 / 改用原图」；选中 AI 插画或相册导入时显示「主视觉柔和阴影」开关 |
| 文字 | 表单字段（见下） | 文字输入框，右侧实时更新到卡片 |

文字字段（`BrewTextField`：上方 9pt 灰色标签 + 内嵌输入框，圆角 17，paperSoft 底）：

| 字段 | 上限 | 默认值（留空时自动生成） |
| --- | --- | --- |
| 中文名（大标题） | 40 字 | 配方名 |
| 英文名（衬线大字） | 44 字 | 按豆子风味 + 分类推导（如 Lychee Cold Brew） |
| 菜单价格 ¥ | 数字 | 配方价格（空 = 不显示价格） |
| 副标题（可选，小字） | 80 字 | 豆子/口感/甜度 |
| 分类（左上角小字） | 20 字 | 由层推导（拿铁/冷萃/特调…） |
| 烘焙度 / 处理法（逗号分隔） | 40 字 | 豆子烘焙度 + 处理法 |
| 配料 · 中文 | 60 字 | 按层自动拼接 |
| 配料 · 英文 / 豆名 | 80 字 | 按层自动英文 + 豆名 |
| 风味参考 · 中文 | 60 字 | 豆子风味 + 口感 + 甜度 |
| 风味参考 · 英文 | 80 字 | 自动英文映射 |
| 底部关键词（逗号分隔） | 40 字 | 前 2 豆子风味 + 口感 + 甜度 |
| 标签（兼容旧数据） | 60 字 | 旧版字段，无默认 |

底部主按钮「完成」（关闭 sheet）。

## 4. AI 插画画板（sheet「AI 插画」）与 AI 文案（sheet「AI 灵感」）

- **AI 插画**：标题「给这杯画一张手绘插画」；插画 prompt 多行输入框（可修改，默认按配方拼）；「按配方重写 prompt」；主按钮「根据这杯配方生成插画 / 重新生成一张」；生成中显示 loading 卡「正在根据这杯配方画插画…（奶油纸底 · 手绘水彩 · 暖色调 · 无文字 · 正方形）」；成功显示方形预览 +「重新生成」「改用本地封面」「完成，回到卡片」；失败显示「插画生成失败」+ 重试；未配置 API 时显示「去设置」。
- **AI 文案**：描述输入框 +「AI 生成文案」；成功显示标题/副标题/标签/主题/模板摘要 +「带着这张卡片继续设计」；失败显示错误 + 重试。
- **相册导入**：PhotosPicker 选图 → 全屏浮层「正在自动抠图…（本机离线处理，背景会变成透明 PNG）」→ 成功写入透明 PNG 并套用；失败弹窗「自动抠图没有成功」（主按钮「使用原图」、次按钮「换一张」）。

## 5. 布局编辑（编辑布局模式）

### 5.1 进入/退出
- 主页面第二行工具栏「编辑布局」→ 卡片上出现所有可见元素的虚线框；按钮文案变「完成布局」。
- 再次点击「完成布局」退出编辑，保留已保存的布局。

### 5.2 卡片上的元素选区
- 未选中：1pt 灰（line 色）虚线框，dash [5,4]，圆角 6pt，无文字标签。
- 选中：1.6pt limeDeep 虚线框 + lime 10% 底色，左上角小标签（lime 底、深墨 8pt 文字）显示元素名：分类/产地、烘焙度/处理法、价格、英文名、中文名、配料行、风味参考、底部关键词、插画/图片。
- 点选元素 → 选中；拖动 → 元素跟随手指移动（实时预览）。
- 拖动限制在卡面内（元素整体不出界）。
- 碰撞检测：与其它可见元素相交时，底部出现红色提示条「元素有重叠：请拖开或点「恢复自动排版」（重叠时不能保存/导出）」；松手仍重叠则自动回退到拖动前位置，并顶部提示「元素会互相遮挡，已回退到上一个位置；也可以点「恢复自动排版」。」
- 保存/导出/分享前若仍存在重叠：拦截并提示「元素有重叠，请先拖开或恢复自动排版，再保存/导出。」

### 5.3 选中元素属性面板（编辑布局时，卡片下方）
- 标题「编辑布局」+ 副标题「在卡片上点选/拖动元素；文字可调字号与对齐，图片可缩放」
- 右上角胶囊按钮「恢复自动排版」
- 元素选择行（横向滚动）：每个元素一个胶囊（选中 lime 底、深墨字；隐藏的元素文字变浅灰），胶囊右侧「眼睛 / 眼睛斜线」按钮切换显示/隐藏
- 选中元素属性（paperSoft 圆角条）：
  - 元素名
  - 文字元素：左/中/右对齐三个图标按钮（text.alignleft / aligncenter / alignright）
  - 缩放：`−` 按钮 / 百分比（50%–200%，步进 5%）/ `+` 按钮
  - 文字元素字号行：`字号` 标签 + Slider（8–72pt，step 1，lime tint）+ 右侧「NNpt」+ 重置按钮（arrow.counterclockwise）
- 冲突提示条（红色圆角，rose 背景，roseDeep 文字）同上。

## 6. 字号规则

- 每个文字元素独立字号：分类/产地、烘焙度/处理法、价格、英文名、中文名、配料行、风味参考、底部关键词。
- 范围 8–72pt（设计点：以 640pt 宽卡面为基准，导出时等比放大到 A6/社交尺寸），Slider 步进 1pt，实时预览。
- 未自定义时使用默认字号（保持原设计比例）：竖版约 分类 13 / 烘焙 11 / 价格 34 / 英文名 64 / 中文名 27 / 配料 13 / 风味 12.5 / 关键词 12；横版按同一比例随卡高换算。
- 字号按横/竖版分别保存；切换比例互不影响。
- 字号变化后自动布局会重新流式排版（不重叠）；手动布局下保持不变并参与碰撞检测。

## 7. 拖拽、位置与持久化

- 每个元素的手动位置以**归一化中心点**保存（centerX/centerY 相对卡宽/卡高 0–1），并保存 `width/height`（归一化，用于换行与碰撞）、`scale`、`alignment`；横/竖版分开保存。
- 首次拖动/缩放/对齐时，将当前自动排版的真实测量位置冻结为手动布局；其它元素保持原位。
- 未拖动过的方向继续使用自动流式排版（按真实文本高度堆叠，不重叠、不出界，A6 与社交都不截断）。
- 模板/横竖版切换时自动清空手动排版并重排（提示「切换模板后已自动重排。」/「切换横竖版后已自动重排。」）。
- 所有文案覆盖、图片路径/来源、字号、隐藏元素、手动位置均写入卡片配置（Recipe.promoCard），旧 JSON 缺字段时按默认自动排版，兼容旧数据。
- 恢复自动排版：清空当前方向的手动位置/缩放，立即回到自动流式排版，并退出编辑布局。

## 8. 视觉规范

- 卡片：奶油纸底（#F5F1E6 附近）+ 细纸纹；细线分隔（ink 20%，0.8pt）；无重投影。
- 主色板（App 动态色，浅色模式）：paper #EDECE7 / card #FBFAF7 / ink #26231F / inkSoft #48433C / muted #8E897E / lime #A3CD39 / limeSoft #EAF2CE / forest #4E5B31 / rose #F0DEDA / roseDeep #B77A6A / lineSoft #E9E6DF。
- 字体：标题/正文使用系统字体；卡片英文名用系统衬线（New York 风格），中文名 Songti/Serif；灰色小字系统无衬线。
- 圆角：sheet 内卡片/按钮 14–20pt；主按钮 51pt 高胶囊；工具栏按钮圆角 18pt；提示条 15pt。
- 与设计无关的变化不做：不加装饰、不改卡片层级/字体样式/纸张。

## 9. 导出 / 分享

- 导出尺寸：A6 300dpi 竖 1240×1748、横 1748×1240；社交竖 1200×1600、横 1200×675。
- 「导出到相册」→ PNG 存系统相册（成功弹窗「已保存到相册」并标注尺寸）；权限拒绝 → 提示 +「去系统设置」。
- 「分享 / 打印」→ 生成临时 PNG 交系统分享面板（含打印）；文件名 `<标题>-A6-300dpi-<时间>.png`。
- 导出/分享与手动排版、字号完全一致（WYSIWYG）。
