# 宣传卡片 v2 · 社交平台「手绘特调咖啡随杯卡」设计规格

> 参考图：`docs/reference/coffee-cards/ref-1.jpg ~ ref-4.jpg`（用户提供的社交平台笔记截图）。
> 定位：**单个配方单品的随杯小卡**（咖啡店打印出来随杯附送/拍照打卡），不是 App 宣传。

## 1. 尺寸与导出
| 用途 | 比例 | 像素（300dpi） |
| --- | --- | --- |
| 竖版 A6（主） | 105:148 | 1240 × 1748 |
| 横版 A6 | 148:105 | 1748 × 1240 |
| 社交竖版（可选） | 3:4 | 1200 × 1600 |
| 社交横版（可选） | 16:9 | 1200 × 675 |

导出 PNG → 系统相册 + 分享（iOS 分享面板含打印；Android ACTION_SEND / 系统打印）。

## 2. 版式（竖版）
1. 纸张：奶油米白纸底（近似 `#F5F1E6`），叠加极细纸纹/颗粒；无渐变、无重投影。
2. 顶部两栏：
   - 左：小分类（拿铁 / 冷萃 / 特调，由配方层推导）；
   - 右：烘焙度/处理法小标签（如 中度烘焙 · 水洗 WASHED）+ 价格 `¥NN`（右下小圆点）。
3. 1px 细横线分隔。
4. 中部文字：
   - 英文名（大号，衬线/New York 感）→ 中文名（次大）；
   - 配料行：`冷萃 | 豆名 | Cold Brew` / `浓缩 | 牛奶 | Espresso`；
   - `风味参考：` + 风味标签（豆子风味 + 口感/甜度）。
5. 插画：中下部 **AI 手绘水彩咖啡插画**（含水果/配料点缀、无文字），约占卡高 35–45%。
6. 底部：2–3 个风味关键词小字 + 极小品牌落款 `BREWKIN · 忆杯手记`。

横版：左侧文字块（分类/价格/名称/配料/风味），右侧 45–55% 插画。

## 3. 字体与颜色
- 纸底 `#F5F1E6`；墨色 `#26231F`；次要文字 `#575046`/`#8E897E`；价格用墨色。
- 英文名用系统衬线（iOS New York / Android serif），中文用系统无衬线；正文小号。

## 4. AI 插画
- 设置页「插画 API」默认预置 **智谱 BigModel CogView-3-Flash**：
  - Base URL `https://open.bigmodel.cn/api/paas/v4`，`POST /images/generations`
  - Body `{"model":"cogview-3-flash","prompt":"...","size":"1024x1024"}`，Header `Authorization: Bearer <Key>`
  - 响应 `data[0].url` → 下载图片存 App 私有目录；兼容第三方网关的 `b64_json`。
- 备用预设：硅基流动 `https://api.siliconflow.cn/v1` + `Kwai-Kolors/Kolors`；自定义 OpenAI 兼容。
- Prompt 结构：主体（中文/英文饮品名）+ 杯型（冷萃杯/拿铁杯/马克杯）+ 层颜色 + 配料点缀 + 固定风格词
  `hand-painted watercolor illustration, cream paper background, warm tone, ingredient garnishes, no text, no letters, centered, square 1024`。
- 可重新生成；可回退本地杯图/豆插画/相册图；未配置 API 时禁用并引导设置。

## 5. 价格字段
- `Recipe.price: Int?`（元；0/空=未设置，旧 JSON 兼容）。
- 保存/编辑配方弹窗可填「菜单价格 ¥」；菜单列表卡片显示 `¥NN`；卡片顶部右侧显示价格 + 小圆点；卡片编辑器也可改。

## 6. 编辑器 v3：全元素编辑 / 拖拽定位 / 防遮挡

- **默认自动填入**：继续按配方、豆子风味、层颜色/杯型、价格自动生成全部文案与主视觉；切换模板、横/竖版或内容变化时**自动重排**。
- **全元素可编辑**：分类、烘焙度/处理法标签、价格、英文名、中文名、配料、风味参考、底部关键词均可直接编辑；插画来源可切换（AI 插画 / 相册导入自动抠图 / 杯图 / 豆插画 / 相册原图）；元素可显示/隐藏。
- **拖拽定位**：点击选中元素出现虚线选框，拖动调整位置；文字支持字号与对齐，图片支持缩放。位置以**归一化比例**保存（相对卡宽/卡高），自动适配 A6 打印与社交尺寸两种比例。
- **绝不遮挡（硬约束）**：
  - 默认布局用测量后的真实文本高度进行流式排版，不重叠、不越界、不截断（超长文本自动缩字号/换行）。
  - 手动拖动限制在卡面安全区内；实时做元素 AABB 碰撞检测：重叠时显示提示并吸附/回退，保存与导出前必须无重叠。
  - 提供「恢复自动排版」按钮；恢复后回到无遮挡默认布局。
- **持久化**：所有文案、图片路径/来源、每元素在横/竖版的归一化位置与缩放都随 Recipe 保存，旧数据兼容。
